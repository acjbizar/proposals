
# rel=designer

Currently, HTML offers link relations for makers in the form of ``author`` and `publisher`. This makes sense in many cases, especially in the context of technical documents, which used to basically be the only type of content on the Web.

However, the Web has evolved a lot, and nowadays, there are many types of content, all with their own properties and relations.

## Examples

```html
<link rel="designer" href="https://alexanderchristiaanjacob.com/" title="Alexander Christiaan Jacob">
```
