
# `rel=artist`

Currently, HTML offers link relations for makers in the form of ``author`` and `publisher`. This makes sense in many cases, especially in the context of technical documents, which used to basically be the only type of content on the Web.

However, the Web has evolved a lot, and nowadays, there are many types of content, all with their own properties and relations. For an internet artwork like [Who’s Afraid of The Blues](https://afraid.blue/), it would make more sense to be linked to an artist, then to an author or publisher.

## Examples

```html
<link rel="artist" href="https://alexanderchristiaanjacob.com/" title="Alexander Christiaan Jacob">
```
