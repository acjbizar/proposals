
# ``@ambilight``

## Properties

<dl>
<dt>`background`</dt>
<dd>Because <dfn>ambilight</dfn> (ambient light) outputs are generally deduced from whatever is shown on the screen, a background — which can define the visual contents of the entire canvas — seems like an appropriate property.</dd>
</dl>

## Examples

```css
@ambilight {
  background: red;
}
```

## Potential concerns

Ambilight was developed, patented, and remains closely associated with the [Philips](https://www.philips.nl/) brand. Perhaps it’s a good idea to give this proposed standard a more neutral name, like ``@ambient-light``, `@background-light`, or `@wall`.
